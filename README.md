# TASTE2 Homepage

Static academic project page for **TASTE2: Text-Aligned Speech Modeling and Deployment toward Full-Duplex Voice Interaction**.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, and publish the repository root from the default branch.
